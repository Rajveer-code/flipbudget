\section{Theory}
\label{sec:theory}

Table~\ref{tab:theory-summary} summarizes every result below with its
novelty class; full derivations are in Appendix~\ref{sec:appendix-proofs}.

\paragraph{T-A (Scorer Sensitivity Model).} $A^\ast$ is identified up to the
box $B$; sharp bounds via 4-corner evaluation when $B$ does not straddle
$\alpha+\beta=1$, via the feasible-region supremum (diverges to $[0,1]$)
when it does. Class B.

\paragraph{T-H (Sharpness).} 4-corner evaluation (non-straddling case) is
exact, not an outer bound---a linear-fractional-function vertex-theorem
argument (illustrated in Appendix~\ref{sec:appendix-figures},
Figure~\ref{fig:identified-set}). Class B.

\paragraph{Ranking-preservation theorem.} $A_1^\ast > A_2^\ast$ for every
$(\alpha,\beta) \in B$ \textbf{iff} $0 \notin \Delta^\ast(B)$---an exact
corollary of T-H, stated as a theorem because it shows sharpness (not mere
conservatism) is what makes the field's existing \code{contains\_zero}
check necessary-and-sufficient, not just sufficient. Class B.

\paragraph{T-B (Design-sensitivity impossibility).} A compound sensitivity
level $\tilde{\Lambda}$ exists beyond which a comparison is unidentifiable
at \emph{any} sample size---a Rosenbaum-style result
\citep{rosenbaum2004design} adapted to this setting. Class B.

\paragraph{Correlated scorer error.} Under a one-factor shared-item-difficulty
model \citep{dawid1979maximum}, non-differential heterogeneity strictly
\emph{reduces} pairwise-difference variance versus independence
($\mathrm{Cov}\geq0$, closed form, simulation-verified); differential
loading breaks this and is what the framework bounds. Class B.

\paragraph{T-D (Imperfect human reference).} A full latent-class treatment
\citep{hui1980estimating} is not justified by this paper's rater-overlap
data (an explicit, evidenced decision). A sensitivity bound $q_{\max}(\eta)$
is derived instead; on real data (0/69 apparent disagreements) it has no
concerning breakdown point for realistic $\eta$ (0--5\%). Class B/C.

\paragraph{T-E (Verification-bias formalization).} Distinct from the
classical verification-bias structure because the sampling probability
$\pi_h$ is known by design---exactly the condition under which
Horvitz--Thompson \citep{horvitz1952generalization} is unbiased. Class B.

\paragraph{Flip-budget uncertainty.} $d^\ast$ (minimum differential-error
perturbation to put a comparison's sign in doubt) is given a bootstrap
treatment rather than a bare point value; on the current roster's most
fragile and robust pairs, 95\% intervals exclude zero cleanly
(Section~\ref{sec:results-flip-budget}). Asymptotic-coverage proof for this
nonlinear, possibly-empty-set estimand is open. Class C.

\paragraph{Partial pooling.} Empirical-Bayes shrinkage propagates a local
audit's effect to un-audited models---stabilizing thin per-model audits,
but also the reason naive plug-in Neyman is \emph{dominated} by uniform
allocation on real sparse data (Section~\ref{sec:audit-design}). Class B/C.

\paragraph{Novelty summary.} No result rises above class C. The
contribution is the \emph{combination}---benchmark comparison $+$ scorer
misclassification $+$ partial identification $+$ audit-estimation
uncertainty $+$ audit-budget design $+$ scorer-choice
dependence---evidenced with real data throughout (full A/B/C/D
classification: Appendix~\ref{sec:appendix-novelty}).
